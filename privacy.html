Privacy policy — rclone-drive-backup

rclone-drive-backup is a personal backup tool used only by its owner.

  • It accesses Google Drive only to upload, list and read the owner's own backup files.
  • OAuth tokens are stored only on the owner's own machines. No data is sent to any third party.
  • No data is collected from, sold to, or shared with anyone else. Google user data is used only to provide the backup function.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Contact: the account that owns the Google Cloud project for this app.
